# deploy/lambda_requirements.txt
# Minimal runtime dependencies for the ZiwaVision Lambda container.
# This is NOT requirements.txt (the full local venv dump).
# The Dockerfile installs only these packages so the image stays within the
# 10 GB Lambda container limit and cold-starts remain fast.
#
# Native libraries (libGL, libgomp, glib2) are installed via dnf in the
# Dockerfile before pip runs. Do NOT add packages here that require system
# libs not already present in the base image.
